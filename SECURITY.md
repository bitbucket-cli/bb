# Reporting security vulnerabilities

Please report suspected vulnerabilities privately to thomas@redstone.me.uk.
Include the affected bb version, operating system, reproduction steps, and
potential impact. Use dummy credentials and remove tokens, client secrets, and
private repository data from examples and logs.

Please avoid opening a public issue with exploit details before the maintainer
has had a chance to investigate. Acknowledgment and fixes depend on maintainer
availability; this project does not promise a fixed response time.

Use the latest available release and its documented patched Go toolchain when
building from source.
